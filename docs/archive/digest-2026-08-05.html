CrowdStrike: AI is now embedded across every stage of adversary operations

↪ Distinct from, but thematically related to, the ongoing Cisco SD-WAN, water-utility PLC, and SonicWall/INC ransomware campaigns tracked in this digest — together they point to AI systems and OT/network infrastructure as the two fastest-growing attack surfaces this year.

CrowdStrike's 2026 Threat Hunting Report finds AI-enabled adversary activity climbed 89% year-over-year, with threat actors using AI to write payloads, exploit AI infrastructure directly, and abuse enterprise LLMs — one campaign fired nearly 200,000 requests at an AI model in two minutes. A North Korea-linked group, CrowdStrike's STARDUST CHOLLIMA, injected malicious code into 131 trusted packages in the open-source Mastra AI agent framework, and 87% of software-registry threats identified in H1 2026 involved malicious npm packages.

What’s new Quantifies a shift that's been discussed anecdotally all year: AI is now both a tool attackers use and, via trusted agent-framework supply chains, a target and attack surface in its own right.
Context

Mastra is an open-source framework developers use to build AI agents. A 'supply-chain' attack like this compromises a widely trusted software component so the malicious code spreads to everyone downstream who depends on it — similar in spirit to the 2020 SolarWinds breach.
