Patched Azure flaw could have let one attacker read or write to any customer's Cosmos DB

Security researchers at Wiz disclosed "CosmosEscape," a flaw that let them escape a Gremlin query sandbox inside Azure Cosmos DB's multi-tenant gateway and extract a platform-wide signing secret. That secret could be used to retrieve the primary key of any customer's Cosmos DB account, granting full read/write access across the service -- including, potentially, Microsoft's own internal databases that run on Cosmos DB. Microsoft has fixed it and says it found no evidence of exploitation outside Wiz's own testing.

What’s new This is a newly disclosed vulnerability (patched, no known active exploitation) -- distinct from the ongoing Cisco SD-WAN campaign, which involves confirmed in-the-wild attacks.
How outlets frame it Both outlets cover this as a technical disclosure rather than a breaking incident; SecurityWeek leans more on Microsoft's remediation timeline, The Hacker News on the scale of what was theoretically exposed.
Context

Azure Cosmos DB is Microsoft's globally distributed, multi-tenant NoSQL database service; Gremlin is a graph-query language it supports. A "primary key" for a Cosmos DB account grants full administrative access to that account's data -- the equivalent of a master password.
