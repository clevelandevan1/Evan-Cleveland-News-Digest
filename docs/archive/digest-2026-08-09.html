Broadcom patches two critical, unauthenticated VMware vCenter flaws with no workaround

Broadcom's July 29 VMSA-2026-0006 advisory patches two critical vCenter Server vulnerabilities, both rated CVSS 9.8: CVE-2026-59309 lets an unauthenticated network attacker bypass authentication via VMware's Directory Service, and CVE-2026-59310 is a directory-traversal bug in the vCenter Syslog Server that can lead to remote code execution. The flaws also touch ESX, Workstation, Fusion and Cloud Foundation. Broadcom says there is no workaround, so patching to the fixed vSphere/Cloud Foundation builds is the only mitigation.

What’s new A newly disclosed, distinct vulnerability pair — not a continuation of the Cisco, SonicWall, TeamCity or N-able incidents already being tracked — and the first VMware-specific critical-infrastructure item surfaced this run.
Context

vCenter Server is the central management console for VMware's virtualization platform, widely used to run enterprise data centers; a flaw here can potentially expose every virtual machine an organization runs on top of it.
