'CoreBreak' flaw let attackers hijack AI agents across AWS, Google, and Vercel

Researchers disclosed a cross-platform vulnerability pattern, dubbed CoreBreak, that let attackers forge tool calls to AI agents hosted on AWS, Google Cloud, and Vercel — reaching backend tools and data without the underlying model ever authorizing the action. Several of the paths bypassed the model entirely. All three vendors have shipped fixes, and the research was presented at Black Hat USA 2026.

What’s new This is a newly disclosed class of vulnerability (not a follow-up to a prior thread): it targets the agent-orchestration layer itself — the plumbing that lets an AI agent call external tools — rather than the model's reasoning, meaning prompt-injection defenses alone wouldn't have caught it.
Context

AI "agents" are LLM-based systems given the ability to call outside tools (databases, APIs, code execution) to complete multi-step tasks. CoreBreak describes a way attackers could send forged tool-call requests directly to that plumbing, skipping the model's own judgment about whether the action should happen — relevant to any enterprise running agentic AI workloads on these three clouds.
