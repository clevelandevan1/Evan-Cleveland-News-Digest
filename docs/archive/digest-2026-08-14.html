Nvidia and SK Group sign $500B+ deal locking down AI-memory supply and new AI factories

↪ Extends the ongoing hyperscaler AI-infrastructure buildout thread (last updated Aug 12 with the Samsung-Broadcom memory/foundry MOU); this is a second major memory-supply lock-in within the same week, reinforcing that HBM capacity, not just capex totals, is now the binding constraint.

Nvidia and SK Group signed letters of intent for a partnership exceeding $500 billion spanning new AI-factory construction and a long-term memory supply agreement. SK Telecom will deploy Nvidia's DSX platform with Vera Rubin accelerators powered by SK hynix's HBM4 memory, with the first AI factory coming online in 2027; separately, SK hynix and Nvidia will codevelop next-generation HBM to meet training and agentic-AI workloads. For Nvidia, it locks in scarce high-bandwidth memory supply at a moment when HBM capacity is one of the industry's tightest bottlenecks; for SK hynix, it locks in a decade-scale anchor customer.

What’s new A concrete, priced deal ($500B+) rather than the vaguer capex guidance and circular-financing debate that dominated this thread through early August — this is Nvidia securing physical memory supply, not just funding commitments.
How outlets frame it Nvidia's own release emphasizes the AI-factory build-out; CNBC's framing is narrower and supply-chain-focused, emphasizing that this is fundamentally about Nvidia locking down scarce HBM memory before rivals can.
Context

HBM (high-bandwidth memory) is a specialized memory type stacked directly next to AI chips for fast data access; it's currently supply-constrained industry-wide, making long-term supply deals like this one a competitive lever as much as a manufacturing agreement.
